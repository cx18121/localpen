# Memory (sub-project A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add implicit voice + facts memory: the local model summarizes a `StyleProfile` from persisted interactions in the background and `MemoryService` injects it action-aware into the two generation entry points, with a recents-pinned inspect/edit surface and durable Forget.

**Architecture:** New `MemoryService` (`@MainActor`) owns profile lifecycle (cache, threshold-triggered background regeneration via `StreamingClient`) and prompt composition (`compose(base:for:seedAction:)`). A new `style_profile` table (migration v3) holds the single evolving row. The two existing generation entry points (`PanelController` one-shot `:589`, conversation `:740`) wrap their base system prompts through `compose`. Every durable user-authored row from either persistence path (`Persistence.save`, `ConversationStore.createThreadWithSeed`, `ConversationStore.appendExchange`) posts a single `localpen.interactionPersisted` `NotificationCenter` notification after commit; `MemoryService` subscribes. Authored-text attribution and a `forgotten_before` tombstone are enforced in the exemplar/generation queries themselves so they're impossible to bypass at call sites.

**Tech Stack:** Swift 5.10, SwiftUI, AppKit, GRDB.swift, llama.cpp via `StreamingClient`, NotificationCenter, XCTest. macOS 14.

**Spec:** [`docs/superpowers/specs/2026-05-27-memory-design.md`](../specs/2026-05-27-memory-design.md). **Roadmap:** [`ROADMAP.md`](../../../ROADMAP.md) sub-project A.

**Working pattern note:** Per the project's `feedback_build_proper_version_not_granular_phases` posture, each task is a coherent unit of work that ends in one commit. Tests are included where they encode intent the spec is built on — especially the regression tests for the four Codex-caught failure modes (third-party text in `respond.selection`, missing conversation-path hook, conversation gating by seed action, durable forget). Build + run all tests at the end of each task; merge to main once Task 9's checks pass.

> **Why v4 — Codex catch:** `ConversationStore` writes `Int64(Date().timeIntervalSince1970 * 1000)` (epoch **milliseconds**) but `PanelController.buildInteraction` writes `Int64(Date().timeIntervalSince1970)` (epoch **seconds**). The Forget tombstone in `forgotten_before` and the eligibility filter compare against `interactions.timestamp` directly — mixed units would let pre-forget conversation rows silently pass any tombstone set in seconds. v4 backfills the seconds-era one-shot rows into ms, and we change the one-shot writer to ms going forward, so every memory query operates in a single unit (ms).

```swift
// Localpen/Models/StyleProfile.swift
import Foundation
import GRDB

/// The single evolving memory row. id is always 1; we upsert.
/// `forgottenBefore` is the durable-forget tombstone: profile generation and exemplar
/// selection MUST filter out interactions with `timestamp < forgottenBefore`. Clearing
/// the card without bumping this would let the next regeneration resurrect the same
/// content from the same source rows — the loophole the spec calls out.
struct StyleProfile: Codable, FetchableRecord, MutablePersistableRecord, Equatable {
    var id: Int64 = 1
    var voiceCard: String?
    /// JSON-encoded `[String]` in storage; in memory always a Swift array.
    /// (We codec the JSON ourselves rather than relying on GRDB's column codec
    /// because the column type is TEXT and we want explicit empty-array semantics.)
    var facts: [String] = []
    var generatedAt: Int64?
    var sampleCount: Int = 0
    var userEdited: Bool = false
    var forgottenBefore: Int64 = 0

    static let databaseTableName = "style_profile"

    enum CodingKeys: String, CodingKey {
        case id
        case voiceCard = "voice_card"
        case factsJSON = "facts"
        case generatedAt = "generated_at"
        case sampleCount = "sample_count"
        case userEdited = "user_edited"
        case forgottenBefore = "forgotten_before"
    }

    init(id: Int64 = 1, voiceCard: String? = nil, facts: [String] = [],
         generatedAt: Int64? = nil, sampleCount: Int = 0,
         userEdited: Bool = false, forgottenBefore: Int64 = 0) {
        self.id = id; self.voiceCard = voiceCard; self.facts = facts
        self.generatedAt = generatedAt; self.sampleCount = sampleCount
        self.userEdited = userEdited; self.forgottenBefore = forgottenBefore
    }

    init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        id = try c.decodeIfPresent(Int64.self, forKey: .id) ?? 1
        voiceCard = try c.decodeIfPresent(String.self, forKey: .voiceCard)
        let raw = try c.decodeIfPresent(String.self, forKey: .factsJSON) ?? "[]"
        facts = (try? JSONDecoder().decode([String].self, from: Data(raw.utf8))) ?? []
        generatedAt = try c.decodeIfPresent(Int64.self, forKey: .generatedAt)
        sampleCount = try c.decodeIfPresent(Int.self, forKey: .sampleCount) ?? 0
        userEdited = try c.decodeIfPresent(Bool.self, forKey: .userEdited) ?? false
        forgottenBefore = try c.decodeIfPresent(Int64.self, forKey: .forgottenBefore) ?? 0
    }

    func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(id, forKey: .id)
        try c.encode(voiceCard, forKey: .voiceCard)
        let data = (try? JSONEncoder().encode(facts)) ?? Data("[]".utf8)
        try c.encode(String(data: data, encoding: .utf8) ?? "[]", forKey: .factsJSON)
        try c.encode(generatedAt, forKey: .generatedAt)
        try c.encode(sampleCount, forKey: .sampleCount)
        try c.encode(userEdited, forKey: .userEdited)
        try c.encode(forgottenBefore, forKey: .forgottenBefore)
    }
}
```

func loadStyleProfile() async -> StyleProfile {

        try StyleProfile.fetchOne(db, key: 1)

}

func saveStyleProfile(_ profile: StyleProfile) async {
    var p = profile; p.id = 1
    do {
        try await dbQueue.write { db in
            try p.save(db)   // upsert: row 1 exists from the migration
        }
    } catch {
        log.error("saveStyleProfile failed: \(error.localizedDescription)")
    }
}

/// Durable forget: clears the card/facts AND sets the tombstone to `at`.
/// `at` is unix epoch **milliseconds** — same unit as `interactions.timestamp`
/// after migration v4. After this, exemplar selection and profile generation
/// ignore rows with timestamp < at — so the next regeneration cannot rebuild
/// from the same history.
func forgetMemory(at: Int64) async {
    do {
        try await dbQueue.write { db in
            try db.execute(sql: """
                UPDATE style_profile
                   SET voice_card = NULL,
                       facts = '[]',
                       generated_at = NULL,
                       sample_count = 0,
                       user_edited = 0,
                       forgotten_before = ?
                 WHERE id = 1
                """, arguments: [at])
        }
    } catch {
        log.error("forgetMemory failed: \(error.localizedDescription)")
    }
}

/// Count of interactions whose timestamp is >= `since` (the forgotten_before tombstone
/// or 0). The cold-start gate and the regeneration threshold both read this count, NOT
/// raw `count()`, so forgotten history can never satisfy a threshold by itself.
func eligibleInteractionCount(since: Int64) async -> Int {
    (try? await dbQueue.read { db in
        try Int.fetchOne(db, sql: "SELECT COUNT(*) FROM interactions WHERE timestamp >= ?",
                         arguments: [since]) ?? 0
    }) ?? 0
}

```swift
// Localpen/Services/MemoryAttribution.swift
import Foundation
import GRDB

/// Per-action policy for what counts as a user-voice sample. The spec's
/// "Authored-text attribution" table, encoded once so neither exemplar selection
/// nor profile generation can drift from it at call sites.
///
/// Rule precedence (highest first):
///   1) `editedOutput` (the user's hand correction) — highest signal, ANY action.
///   2) For `.respond`, NEVER use `selection` (that's the third-party message
///      being replied to). Fall through to model_output ONLY when accepted.
///   3) For conversation rows (thread_id != NULL), use `custom_prompt` — the
///      user's follow-up text. `selection` is always NULL there per ConversationStore.
///   4) Otherwise (proofread/polish/moreFormal/moreCasual/shorter/custom one-shot
///      with non-empty selection), `selection` IS the user's text.
///
/// The query below is the ONLY place this precedence is encoded. Tests assert it
/// row-by-row.
enum MemoryAttribution {

    /// Exemplar selection: returns up to `limit` qualifying samples respecting the
    /// forget tombstone and per-action attribution. Returns ordered-by-recency in
    /// tests (`shuffle: false`) for determinism; `shuffle: true` for production.
    ///
    /// The CASE ordering encodes the spec's attribution policy. Critical: raw
    /// `model_output` is NEVER a user-voice sample — even an accepted reply was
    /// composed by the model, not the user, and using it would train memory on
    /// the model's own style (drift inducer). The user-authored sources for a
    /// `.respond` row are `edited_output` (if it differs from the model's output)
    /// and `custom_prompt` (how the user steered the reply).
    static func selectExemplars(in db: Database,
                                forgottenBefore: Int64,
                                limit: Int,
                                shuffle: Bool) throws -> [String] {
        let poolSize = max(limit * 4, 20)
        let rows = try Row.fetchAll(db, sql: """
            SELECT
              CASE
                -- highest signal: user's hand correction of the model output
                WHEN edited_output IS NOT NULL
                     AND edited_output <> COALESCE(model_output, '')
                     AND length(edited_output) >= 20 THEN edited_output
                -- respond: selection is third-party content; the user's steer
                -- phrasing (custom_prompt) IS legitimate user-voice signal.
                WHEN action = 'respond' THEN custom_prompt
                -- conversation: selection is always NULL; user follow-up is in custom_prompt.
                WHEN thread_id IS NOT NULL THEN custom_prompt
                -- custom one-shot with empty selection: fall back to the user's
                -- instruction text (how the user phrases requests).
                WHEN action = 'custom' AND (selection IS NULL OR length(selection) = 0)
                     THEN custom_prompt
                -- everything else: selection IS the user's own writing.
                ELSE selection
              END AS sample
            FROM interactions
            WHERE timestamp >= ?
            ORDER BY timestamp DESC, id DESC
            LIMIT ?
            """, arguments: [forgottenBefore, poolSize])

        var seen = Set<String>()
        var samples: [String] = []
        for row in rows {
            guard let s: String = row["sample"], (20...1200).contains(s.count) else { continue }
            let key = String(s.prefix(80))   // crude near-dup guard
            if seen.insert(key).inserted { samples.append(s) }
        }
        let picked = shuffle ? Array(samples.shuffled().prefix(limit)) : Array(samples.prefix(limit))
        return picked
    }

    /// Profile-generation input: returns up to `cap` (recent, eligible) samples
    /// labeled by source for the summarization prompt. Same attribution policy as
    /// `selectExemplars`, but emits a struct so the prompt builder can prioritize
    /// editedOutput rows and label sources.
    struct Sample: Equatable {
        let text: String
        let source: Source
        enum Source: String, Equatable {
            case userText           // user's own writing (selection on non-respond rows)
            case userEdit           // user's hand correction of model output (must differ from model_output)
            case replySteer         // user's steer phrasing on a .respond row (custom_prompt)
            case customSteer        // user's instruction on a .custom one-shot with empty selection
            case conversationTurn   // user's follow-up in a thread (custom_prompt)
        }
    }

    static func collectGenerationSamples(in db: Database,
                                         forgottenBefore: Int64,
                                         cap: Int) throws -> [Sample] {
        let rows = try Row.fetchAll(db, sql: """
            SELECT action, selection, custom_prompt, model_output, edited_output, accepted, thread_id
            FROM interactions
            WHERE timestamp >= ?
            ORDER BY timestamp DESC, id DESC
            LIMIT ?
            """, arguments: [forgottenBefore, cap * 3])

        var out: [Sample] = []
        out.reserveCapacity(cap)
        for row in rows {
            let action: String = row["action"] ?? "custom"
            let selection: String? = row["selection"]
            let customPrompt: String? = row["custom_prompt"]
            let modelOutput: String? = row["model_output"]
            let editedOutput: String? = row["edited_output"]
            let accepted: Bool = (row["accepted"] as Int64? ?? 0) == 1
            let threadID: Int64? = row["thread_id"]

            // Precedence (mirrors the SQL CASE above):
            //   1) user's hand correction (must differ from model_output) — highest signal
            //   2) respond → custom_prompt only (the steer); never model_output (model's style)
            //   3) conversation rows → custom_prompt (selection is always NULL there)
            //   4) custom with empty selection → custom_prompt (the user's instruction)
            //   5) otherwise selection (the user's own writing)
            if let e = editedOutput, e != (modelOutput ?? ""), e.count >= 20 {
                out.append(.init(text: e, source: .userEdit))
            } else if action == "respond" {
                if let c = customPrompt, c.count >= 20 {
                    out.append(.init(text: c, source: .replySteer))
                }
                // raw model_output is the model's style, NOT user voice — skip.
            } else if threadID != nil {
                if let c = customPrompt, c.count >= 20 {
                    out.append(.init(text: c, source: .conversationTurn))
                }
            } else if action == "custom", (selection ?? "").isEmpty {
                if let c = customPrompt, c.count >= 20 {
                    out.append(.init(text: c, source: .customSteer))
                }
            } else if let s = selection, s.count >= 20 {
                out.append(.init(text: s, source: .userText))
            }
            _ = accepted   // currently unused; kept in the SELECT so future signals can read it
            if out.count >= cap { break }
        }
        return out
    }
}
```

// LocalpenTests/MemoryAttributionTests.swift
import XCTest
import GRDB
@testable import Localpen

final class MemoryAttributionTests: XCTestCase {

    private func freshQueue() throws -> DatabaseQueue {
        let q = try DatabaseQueue()
        try Persistence.migrate(q)
        return q
    }

    private func insert(_ q: DatabaseQueue, _ rows: [(action: String, sel: String?, custom: String?, output: String?, edited: String?, accepted: Bool, thread: Int64?, ts: Int64)]) throws {
        try q.write { db in
            for r in rows {
                if let t = r.thread {
                    try db.execute(sql: "INSERT OR IGNORE INTO threads (id, created_at, updated_at) VALUES (?, ?, ?)",
                                   arguments: [t, r.ts, r.ts])
                }
                try db.execute(sql: """
                    INSERT INTO interactions
                      (timestamp, source_app, selection, action, custom_prompt, model_id, model_output, accepted, edited_output, thread_id)
                    VALUES (?, NULL, ?, ?, ?, 'm', ?, ?, ?, ?)
                    """, arguments: [r.ts, r.sel, r.action, r.custom, r.output, r.accepted ? 1 : 0, r.edited, r.thread])
            }
        }
    }

    // Headline regression: a respond row has THREE candidate fields, and only ONE
    // is the user's own writing.
    //   - selection      = the third-party incoming message → MUST be excluded
    //   - model_output   = the model's composition (even if user accepted it) →
    //                      MUST be excluded; using it would train on the model's
    //                      own style and induce drift
    //   - custom_prompt  = the user's steer phrasing → INCLUDED, that's their voice
    //   - edited_output  = the user's hand correction of model_output → INCLUDED
    //                      when it differs from model_output
    func test_respond_attributionPicksOnlyUserAuthoredFields() throws {
        let q = try freshQueue()
        let inbound = String(repeating: "incoming third-party message text here ", count: 2)
        let modelReply = String(repeating: "thanks, will follow up tomorrow morning ", count: 2)
        let userSteer = "be brief and decline politely without over-explaining the reason"
        let userEdit  = String(repeating: "I will pass on this one, thanks. ", count: 2)
        try insert(q, [
            (action: "respond", sel: inbound, custom: userSteer,
             output: modelReply, edited: nil,     accepted: true,  thread: nil, ts: 100),
            (action: "respond", sel: inbound, custom: userSteer,
             output: modelReply, edited: userEdit, accepted: true, thread: nil, ts: 101),
        ])

        let picked = try q.read { db in
            try MemoryAttribution.selectExemplars(in: db, forgottenBefore: 0, limit: 5, shuffle: false)
        }
        XCTAssertFalse(picked.contains { $0.contains("incoming third-party") },
                       "respond.selection is third-party text — never user voice")
        XCTAssertFalse(picked.contains { $0.contains("thanks, will follow up") },
                       "respond.model_output is the model's style — never user voice")
        XCTAssertTrue(picked.contains { $0.contains("decline politely") },
                      "the user's steer (custom_prompt) IS user voice for respond")
        XCTAssertTrue(picked.contains { $0.contains("I will pass on this one") },
                      "the user's hand-corrected reply (edited_output) IS the highest signal")
    }

    func test_custom_emptySelection_fallsBackToCustomPrompt() throws {
        let q = try freshQueue()
        let instr = "rewrite the next email I send to sound less apologetic but still warm"
        try insert(q, [
            (action: "custom", sel: nil, custom: instr,
             output: nil, edited: nil, accepted: false, thread: nil, ts: 110),
        ])
        let picked = try q.read { db in
            try MemoryAttribution.selectExemplars(in: db, forgottenBefore: 0, limit: 5, shuffle: false)
        }
        XCTAssertTrue(picked.contains { $0.contains("less apologetic") },
                      "custom one-shot with empty selection: custom_prompt is the user-voice fallback")
    }

    func test_conversationRows_useCustomPromptNotSelection() throws {
        let q = try freshQueue()
        let follow = String(repeating: "can you make it warmer please ", count: 2)
        try insert(q, [
            (action: "polish", sel: nil, custom: follow, output: "ok",
             edited: nil, accepted: false, thread: 7, ts: 200),
        ])

        let picked = try q.read { db in
            try MemoryAttribution.selectExemplars(in: db, forgottenBefore: 0, limit: 5, shuffle: false)
        }
        XCTAssertTrue(picked.contains { $0.contains("can you make it warmer") },
                      "conversation follow-ups live in custom_prompt, must be picked up")
    }

    func test_editedOutputBeatsAnythingElse() throws {
        let q = try freshQueue()
        let original  = String(repeating: "the original draft text here ", count: 2)
        let corrected = String(repeating: "the user's hand-corrected version here ", count: 2)
        try insert(q, [
            (action: "polish", sel: original, custom: nil, output: "model output",

        let samples = try q.read { db in

        }
        XCTAssertEqual(samples.first?.source, .userEdit)
        XCTAssertTrue(samples.first?.text.contains("hand-corrected") ?? false)

    func test_forgottenBefore_excludesPreForgetRows() throws {
        let q = try freshQueue()
        let oldText = String(repeating: "old writing from before forget ", count: 2)
        let newText = String(repeating: "fresh writing after the tombstone ", count: 2)

// Localpen/Services/MemoryService.swift
import Foundation
import GRDB
import os

@MainActor
class MemoryService {   // not `final`: MemoryRegenerationTests overrides scheduleGeneration to spy without firing llama-server
    let persistence: Persistence
    let streaming: StreamingClient
    private let log = Logger(subsystem: "app.localpen.Localpen", category: "Memory")

    /// Cached profile; refreshed after generation or external save. UI inspects it
    /// directly through `currentProfile()`.
    private var cached: StyleProfile = StyleProfile()

    /// Single-flight gate for background generation. Filled by Task 5.
    private var generationTask: Task<Void, Never>?

    /// Compose injection thresholds (spec). Held as constants here so tests can pin them.
    static let coldStartGate = 15
    static let regenGrowthFactor = 1.5
    static let exemplarLimit = 5
    static let generationSampleCap = 40

    init(persistence: Persistence, streaming: StreamingClient) {
        self.persistence = persistence
        self.streaming = streaming
        Task { await self.refreshCache() }
    }

    func refreshCache() async {
        cached = await persistence.loadStyleProfile()
    }

    func currentProfile() -> StyleProfile { cached }

    /// External mutation (UI edit / Regenerate / Forget) re-syncs the cache.
    func saveProfile(_ p: StyleProfile) async {
        await persistence.saveStyleProfile(p)
        cached = p
    }

    func forget(at: Int64 = Int64(Date().timeIntervalSince1970 * 1000)) async {
        // `at` is unix-epoch MILLISECONDS to match interactions.timestamp post-v4.
        await persistence.forgetMemory(at: at)
        cached = StyleProfile(forgottenBefore: at)
    }

    // MARK: - Composition

    /// Returns the system prompt to send to the model, with action-aware memory
    /// injection. `seedAction` is non-nil for conversation calls; the gating action
    /// is `seedAction ?? action`. The matrix is encoded ONCE here so the call sites
    /// can never disagree about whether a given mode gets voice / facts / exemplars.
    func compose(base: String, for action: Action, seedAction: Action? = nil) -> String {
        let gating = seedAction ?? action
        let injectVoice    = Self.injectsVoice(gating)
        let injectFacts    = Self.injectsFacts(gating)
        let injectExemplar = Self.injectsExemplars(gating)

        // Cold-start gate: no card injection if we don't have one yet.
        let cardEligible = injectVoice && (cached.voiceCard?.isEmpty == false)
        let factsEligible = injectFacts && !cached.facts.isEmpty
        let exemplars = injectExemplar ? loadExemplars() : []

        if !cardEligible && !factsEligible && exemplars.isEmpty { return base }

        var out = base
        if cardEligible, let card = cached.voiceCard {
            out += "\n\nUser writing voice:\n\(card)"
        }
        if factsEligible {
            out += "\n\nFacts about the user:\n" + cached.facts.map { "- \($0)" }.joined(separator: "\n")
        }
        if !exemplars.isEmpty {
            out += "\n\nSamples of the user's own writing (for tone reference only — do NOT copy content):\n---\n"
            out += exemplars.joined(separator: "\n---\n")
            out += "\n---"
        }
        return out
    }

    private func loadExemplars() -> [String] {
        let before = cached.forgottenBefore
        return (try? persistence.dbQueue.read { db in
            try MemoryAttribution.selectExemplars(in: db, forgottenBefore: before,
                                                  limit: Self.exemplarLimit, shuffle: true)
        }) ?? []
    }

    // MARK: - Gating matrix

    /// Voice card injection — see spec §"Injection rules (action-aware)".
    /// Excluded: proofread (no drift), shorter (mechanical), respond's reading
    /// surface (the AI is composing new text; voice IS used here because the
    /// USER is the composer being mimicked).
    static func injectsVoice(_ action: Action) -> Bool {
        switch action {
        case .proofread, .shorter: return false
        case .polish, .moreFormal, .moreCasual, .respond, .custom: return true
        }
    }

    /// Facts only where the model composes new content directed at people/projects.
    static func injectsFacts(_ action: Action) -> Bool {
        switch action {
        case .respond, .custom: return true
        default: return false
        }
    }

    static func injectsExemplars(_ action: Action) -> Bool {
        injectsVoice(action)
    }

    // MARK: - Regeneration (skeleton — implemented in Task 5)

    /// Post-commit hook entry point. Wired in Task 4; implementation in Task 5.
    func interactionDidPersist() {
        // no-op until Task 5
    }
}

@MainActor
class MemoryService {
    // ...existing properties from Task 3...

    private var observer: NSObjectProtocol?

    init(persistence: Persistence, streaming: StreamingClient) {
        self.persistence = persistence
        self.streaming = streaming
        Task { await self.refreshCache() }
        self.observer = NotificationCenter.default.addObserver(
            forName: .interactionPersisted, object: nil, queue: .main
        ) { [weak self] _ in
            // queue: .main is enough for serialization; we hop to the MainActor explicitly.
            Task { @MainActor [weak self] in self?.interactionDidPersist() }
        }
    }

    deinit {
        if let observer { NotificationCenter.default.removeObserver(observer) }
    }

    /// Post-commit entry point. Decides (cheaply) whether to schedule a regen.
    /// Single-flight: a second call while a generation is in flight is dropped.
    func interactionDidPersist() {
        guard generationTask == nil else { return }
        if cached.userEdited { return }   // user's hand-tuned profile is ground truth

        Task { [weak self] in
            guard let self else { return }
            let before = self.cached.forgottenBefore
            let eligible = await self.persistence.eligibleInteractionCount(since: before)
            // Cold-start gate (no card under 15 eligible interactions).
            guard eligible >= Self.coldStartGate else { return }
            // Regenerate when grown ≥1.5× since last successful generation.
            // First generation: cached.sampleCount == 0 → threshold is coldStartGate.
            let threshold = max(Self.coldStartGate, Int(Double(self.cached.sampleCount) * Self.regenGrowthFactor))
            guard eligible >= threshold else { return }
            self.scheduleGeneration(eligibleAt: eligible)
        }
    }

    /// Stub. Task 5 fills this with the actual llama-server call. Held single-flight
    /// behind `generationTask`.

```swift
// Inside MemoryService:

// MemoryService is @MainActor, which makes static members actor-isolated by default
// and uncallable from non-@MainActor XCTest cases. The pure helpers below are
// stateless and safe to call from anywhere — mark them `nonisolated` explicitly.

nonisolated static let generationSystemPrompt: String = """
    You analyze a user's writing samples and produce a compact voice profile and a \
    conservative list of facts about them. Return STRICT JSON of the form:
    {"voice_card": "...", "facts": ["...", "..."]}
    Rules:
    - voice_card: 150-250 words. Describe concrete, perceptible traits across: tone/register \
      (and how it shifts), formality, typical sentence length & rhythm, vocabulary register, \
      signature words to favor or avoid, punctuation & casing habits, openings/sign-offs, \
      emoji & emphasis usage, contractions/hedging/directness. Do NOT invent traits not \
      evidenced in the samples.
    - facts: short, high-confidence bullets ONLY (name, role if stated, recurring people/\
      projects, hard preferences). If a candidate fact is uncertain, OMIT it. An empty \
      "facts": [] is correct and preferred over speculation.
    - Output ONLY the JSON object, no preamble, no commentary, no code fences.
    """

func runGeneration(eligibleAt: Int) async {
    // Pull samples through the attribution layer.
    let before = cached.forgottenBefore
    let samples: [MemoryAttribution.Sample] = (try? persistence.dbQueue.read { db in
        try MemoryAttribution.collectGenerationSamples(in: db, forgottenBefore: before,
                                                       cap: Self.generationSampleCap)
    }) ?? []
    guard samples.count >= Self.coldStartGate else {
        log.info("regen aborted: only \(samples.count) eligible samples (< coldStartGate)")
        return
    }

    let userPrompt = Self.buildGenerationUserPrompt(samples: samples)
    var raw = ""
    do {
        for try await tok in streaming.complete(systemPrompt: Self.generationSystemPrompt,
                                                userText: userPrompt) {
            raw += tok
        }
    } catch {
        log.error("regen streaming failed: \(error.localizedDescription)")
        return   // keep previous profile
    }

    guard let parsed = Self.parseProfileJSON(raw) else {
        log.error("regen JSON parse failed; keeping previous profile")
        return
    }

    var next = cached
    next.voiceCard = parsed.voiceCard
    next.facts = parsed.facts
    next.generatedAt = Int64(Date().timeIntervalSince1970 * 1000)  // ms (post-v4 invariant)
    // sampleCount = the basis the profile was actually built from, NOT raw
    // eligibleAt. With generationSampleCap=40 and 100 eligible rows, the profile
    // is built from 40 samples; recording 100 would delay the next regen to 150
    // eligible (1.5×) and leave the profile stale after substantial new data.
    next.sampleCount = samples.count
    next.userEdited = false
    await persistence.saveStyleProfile(next)
    cached = next
    log.info("regen committed: \(parsed.voiceCard.count) chars, \(parsed.facts.count) facts, basis=\(samples.count)")
}

nonisolated static func buildGenerationUserPrompt(samples: [MemoryAttribution.Sample]) -> String {
    // Label sources so the model can weight edits highest. Truncate per-sample at 600 chars.
    var s = "Samples (most recent first):\n"
    for sample in samples {
        let label: String = {
            switch sample.source {
            case .userEdit:           return "[edit — user's correction]"
            case .userText:           return "[own writing]"
            case .replySteer:         return "[user's steer on a reply]"
            case .customSteer:        return "[user's instruction]"
            case .conversationTurn:   return "[user's chat turn]"
            }
        }()
        let body = sample.text.count > 600 ? String(sample.text.prefix(600)) + "…" : sample.text
        s += "\n\(label)\n\(body)\n"
    }
    return s
}

/// Tolerant JSON parser: strips code fences if the model added them, finds the first
/// '{' and the matching closing '}', tries to decode. Returns nil on any failure;
/// callers preserve the previous profile.
nonisolated static func parseProfileJSON(_ raw: String) -> (voiceCard: String, facts: [String])? {
    var s = raw.trimmingCharacters(in: .whitespacesAndNewlines)
    if s.hasPrefix("```") {
        // strip ```json … ``` fence
        if let first = s.range(of: "\n") { s = String(s[first.upperBound...]) }
        if let last = s.range(of: "```", options: .backwards) { s = String(s[..<last.lowerBound]) }
        s = s.trimmingCharacters(in: .whitespacesAndNewlines)
    }
    guard let openIdx = s.firstIndex(of: "{"),
          let closeIdx = s.lastIndex(of: "}"), closeIdx > openIdx else { return nil }
    let jsonText = String(s[openIdx...closeIdx])
    struct Decoded: Decodable { let voice_card: String; let facts: [String]? }
    guard let data = jsonText.data(using: .utf8),
          let d = try? JSONDecoder().decode(Decoded.self, from: data),
          !d.voice_card.isEmpty else { return nil }
    return (d.voice_card, d.facts ?? [])
}
```
