# Free-form Ask + Context Intake — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pivot the hotkey from pure selection-transformer to "ask anything" — empty selection opens directly into a free-form ask input with cheap auto-context (app + window title + selection), while preserving the selection-transformer core unchanged.

**Architecture:** New `Action.ask(question:withSelection:)` whose `operationClass` derives from the flag (revise iff selection chip survived submit). `ContextProbe` reads window title off-main with `AXUIElementSetMessagingTimeout` (the only enforceable freeze guard) and accepts a pre-captured selection so the no-selection hotkey path captures TextIO only once. New `ConversationStore.createThreadForAsk` factory uses the question as title source. Memory attribution gets explicit ask branches in both SQL (`selectExemplars`) and Swift (`collectGenerationSamples`) paths.

**Tech Stack:** Swift 5.10, SwiftUI, AppKit, `@MainActor` / `@Observable`, GRDB.swift, `ApplicationServices` (AX), XCTest. Builds via XcodeGen + xcodebuild.

**Branch:** `ask` (already created from `main` at `682874e`). Spec at [docs/superpowers/specs/2026-05-28-ask-design.md](../specs/2026-05-28-ask-design.md), commit `fcb66a2`. Three Codex adversarial review rounds completed; the load-bearing invariants below come from those.

**Load-bearing invariants (do not weaken):**
1. **Single TextIO capture** in the no-selection hotkey path — `presentForHotkey` calls `TextIO.captureSelection()` once; `ContextProbe.capture(reusingCapture:)` does not call TextIO again.
2. **Off-main AX read** + `AXUIElementSetMessagingTimeout` for freeze guard. Task cancellation alone is not enforceable against a blocked synchronous C call.
3. **`operationClass` derives from `withSelection`** — `revise` when selection chip survived, `create` otherwise.
4. **`withSelection` rehydrates on conversation resume** by reading the persisted Interaction row's `selection` column.
5. **Explicit ask branches in BOTH attribution paths** — SQL `selectExemplars` AND Swift `collectGenerationSamples`. Defense in depth; the `thread_id IS NOT NULL` clause currently masks correct behavior, but a future refactor could silently break attribution.
6. **`createThreadForAsk` uses the question as title source** — `original_selection` column gets the question text so Recent isn't blank for no-selection asks.

import Foundation

enum Action: Hashable, Identifiable {
    case proofread
    case polish
    case moreFormal
    case moreCasual
    case shorter
    case respond(String)
    case custom(String)
    /// Free-form ask. `withSelection` is decided at submit time from whether the
    /// AskContext selection chip survived; `operationClass` derives from it so
    /// the existing accept-path predicate (`operationClass == .revise`) works
    /// unchanged. The flag is NOT serialized in `rawValue`; it's rehydrated on
    /// resume by reading the persisted Interaction row's `selection` column
    /// (passed to `reconstruct`). See docs/superpowers/specs/2026-05-28-ask-design.md.
    case ask(question: String, withSelection: Bool)

    var id: String { rawValue }

    var rawValue: String {
        switch self {
        case .proofread:   return "proofread"
        case .polish:      return "polish"
        case .moreFormal:  return "more_formal"
        case .moreCasual:  return "more_casual"
        case .shorter:     return "shorter"
        case .respond:     return "respond"
        case .custom:      return "custom"
        case .ask:         return "ask"
        }
    }

    /// Inverse of `rawValue` — keep the two in sync when adding a case.
    /// `selection` is read from the persisted Interaction row and only consulted
    /// for `.ask` (to rehydrate the `withSelection` flag). Existing cases ignore
    /// it, so the signature extension is additive.
    static func reconstruct(rawValue: String, steer: String?, selection: String? = nil) -> Action {
        switch rawValue {
        case "proofread":   return .proofread
        case "polish":      return .polish
        case "more_formal": return .moreFormal
        case "more_casual": return .moreCasual
        case "shorter":     return .shorter
        case "respond":     return .respond(steer ?? "")
        case "ask":
            return .ask(question: steer ?? "",
                        withSelection: !(selection ?? "").isEmpty)
        default:            return .custom(steer ?? "")
        }
    }

    var label: String {
        switch self {
        case .proofread:   return "Proofread"
        case .polish:      return "Polish"
        case .moreFormal:  return "More formal"
        case .moreCasual:  return "More casual"
        case .shorter:     return "Shorter"
        case .respond:     return "Respond"
        case .custom:      return "Custom…"
        case .ask:         return "Ask"
        }
    }

    var pillLabel: String { label.replacingOccurrences(of: "…", with: "") }

    var seedSentence: String {
        switch self {
        case .proofread:                  return "Proofread this"
        case .polish:                     return "Polish this"
        case .moreFormal:                 return "Make this more formal"
        case .moreCasual:                 return "Make this more casual"
        case .shorter:                    return "Make this shorter"
        case .respond(let steer):         return steer.isEmpty ? "Respond to this" : steer
        case .custom(let instr):          return instr.isEmpty ? "Custom instruction" : instr
        case .ask(let q, _):              return q.isEmpty ? "Ask" : q
        }
    }

    static let fixed: [Action] = [.proofread, .polish, .moreFormal, .moreCasual, .shorter]

    enum OperationClass {
        case revise
        case create
    }

    /// .ask: revise iff a selection chip survived submit; otherwise create.
    /// This is the resolution to Codex review HIGH 2 — keeping operationClass
    /// as the single source of truth for paste-back behavior, derived per
    /// instance via the withSelection flag.
    var operationClass: OperationClass {
        switch self {
        case .respond:                    return .create
        case .ask(_, let withSelection):  return withSelection ? .revise : .create
        default:                          return .revise
        }
    }

    var steerText: String? {
        switch self {
        case .custom(let t):       return t.isEmpty ? nil : t
        case .respond(let t):      return t.isEmpty ? nil : t
        case .ask(let q, _):       return q.isEmpty ? nil : q
        default:                   return nil
        }
    }

    static func fromCompose(base: Action, text: String) -> Action? {
        let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
        switch base {
        case .custom:  return trimmed.isEmpty ? nil : .custom(trimmed)
        case .respond: return .respond(trimmed)
        case .ask(_, let withSelection):
            return trimmed.isEmpty ? nil : .ask(question: trimmed, withSelection: withSelection)
        default:       return nil
        }
    }
}

import Foundation

/// User-facing representation of context attached to a free-form ask. Each
/// non-nil field renders as a removable chip above the AskInput. Clearing a
/// chip nils the field; submitting takes a final snapshot of what survived.
struct AskContext: Equatable {
    var appLabel: String?    // "Mail · Re: budget Q3" — formatted from probe snapshot
    var selection: String?   // raw text; the chip shows a "N words selected" summary

    static let empty = AskContext()

    /// Builds an AskContext from a ContextProbe snapshot. Formats the appLabel
    /// as "<app> · <window>" when both are present, falls back gracefully.
    static func from(_ snapshot: ContextProbe.Snapshot) -> AskContext {
        let label: String?
        switch (snapshot.appName, snapshot.windowTitle) {
        case (let app?, let title?):  label = "\(app) · \(title)"
        case (let app?, nil):         label = app
        case (nil, let title?):       label = title
        case (nil, nil):              label = nil
        }
        return AskContext(appLabel: label, selection: snapshot.selection)
    }
}

```swift
import Foundation
import AppKit
import ApplicationServices

/// Cheap context capture for free-form Ask. Reads frontmost app name (no
/// permission), focused window title (off-main, AX-timeout-bounded), and
/// optionally reuses an already-paid TextIO capture so the hotkey path
/// doesn't double-pay the ~90ms clipboard settle.
///
/// Codex review v2: AX call is OFF MAIN (detached Task) and bounded via
/// AXUIElementSetMessagingTimeout. Task cancellation cannot preempt a blocked
/// synchronous C call — only the AX-layer timeout is enforceable.
///
/// Codex review v3: `capture(reusingCapture:)` accepts a pre-captured
/// TextIO.Capture so PanelController.captureAndShow can hand its already-paid
/// capture in instead of forcing a second ⌘C synthesis.
final class ContextProbe {

    // MARK: Snapshot

    struct Snapshot: Sendable, Equatable {
        let appName: String?
        let windowTitle: String?
        let selection: String?
    }

    // MARK: Injection seams

    protocol AXWindowTitleReader: Sendable {
        func readWindowTitle(pid: pid_t, timeoutSeconds: Float) -> String?
    }

    protocol SelectionCapturing: Sendable {
        func captureSelectionForProbe() async -> String?
    }

    private let axReader: any AXWindowTitleReader
    private let textIO: any SelectionCapturing
    private let appName: @Sendable () -> String?
    private let pid: @Sendable () -> pid_t

    init(axReader: any AXWindowTitleReader = SystemAXWindowTitleReader(),
         textIO: any SelectionCapturing = TextIOProbeAdapter(),
         appName: @escaping @Sendable () -> String? = {
             NSWorkspace.shared.frontmostApplication?.localizedName
         },
         pid: @escaping @Sendable () -> pid_t = {
             NSWorkspace.shared.frontmostApplication?.processIdentifier ?? 0
         }) {
        self.axReader = axReader
        self.textIO = textIO
        self.appName = appName
        self.pid = pid
    }

    // MARK: Capture

    /// Capture cheap context. If `reusingCapture` is non-nil, its selection
    /// and sourceAppName are reused (the single-capture invariant — see spec
    /// §3.2). If nil, the probe calls TextIO and NSWorkspace itself.
    func capture(reusingCapture: TextIO.Capture?) async -> Snapshot {
        let resolvedAppName: String?
        let selectionTextRaw: String?

        if let cap = reusingCapture {
            resolvedAppName = cap.sourceAppName
            selectionTextRaw = cap.selection
        } else {
            resolvedAppName = appName()
            selectionTextRaw = await textIO.captureSelectionForProbe()
        }
        let normalizedSelection = (selectionTextRaw ?? "").isEmpty ? nil : selectionTextRaw

        // Off-main AX read with AX-layer timeout. The detached Task keeps the
        // main actor free; the timeoutSeconds value is passed to the AX call's
        // AXUIElementSetMessagingTimeout, which IS preemption-effective.
        let pidValue = pid()
        let reader = axReader
        let windowTitle: String? = await Task.detached(priority: .userInitiated) {
            reader.readWindowTitle(pid: pidValue, timeoutSeconds: 0.15)
        }.value

        return Snapshot(appName: resolvedAppName,
                        windowTitle: windowTitle,
                        selection: normalizedSelection)
    }
}

// MARK: Production AX reader

/// Production implementation: sets AX messaging timeout BEFORE the attribute
/// read so the synchronous C call cannot block longer than `timeoutSeconds`.
struct SystemAXWindowTitleReader: ContextProbe.AXWindowTitleReader {
    func readWindowTitle(pid: pid_t, timeoutSeconds: Float) -> String? {
        guard pid > 0 else { return nil }
        let app = AXUIElementCreateApplication(pid)
        AXUIElementSetMessagingTimeout(app, timeoutSeconds)
        var windowRef: CFTypeRef?
        let windowErr = AXUIElementCopyAttributeValue(app, kAXFocusedWindowAttribute as CFString, &windowRef)
        guard windowErr == .success, let window = windowRef else { return nil }
        let win = window as! AXUIElement
        AXUIElementSetMessagingTimeout(win, timeoutSeconds)
        var titleRef: CFTypeRef?
        let titleErr = AXUIElementCopyAttributeValue(win, kAXTitleAttribute as CFString, &titleRef)
        guard titleErr == .success, let title = titleRef as? String else { return nil }
        return title.isEmpty ? nil : title
    }
}

/// Used only when `reusingCapture` is nil — i.e. callers that didn't already
/// pay for capture.
struct TextIOProbeAdapter: ContextProbe.SelectionCapturing {
    func captureSelectionForProbe() async -> String? {
        await MainActor.run { TextIO() }
            .captureSelection()
            .selection
    }
}

import Foundation

/// Pure routing decision for the hotkey path, extracted from PanelController
/// so the no-selection → ask routing (and the single-capture invariant) can
/// be unit-tested without spinning up the full panel. See spec §3.5.
enum HotkeyRouting {
    enum Route: Equatable {
        case menu       // selection present — show the quick-action menu
        case ask        // no selection — show free-form ask input
    }

    static func route(for capture: TextIO.Capture) -> Route {
        let trimmed = (capture.selection ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
        return trimmed.isEmpty ? .ask : .menu
    }
}
```
